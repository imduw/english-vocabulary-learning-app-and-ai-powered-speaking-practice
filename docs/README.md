# Project Documentation

Thư mục này được sử dụng để lưu trữ toàn bộ tài liệu dự án trong tương lai.

## Mục đích các tài liệu sẽ được bổ sung
- **Requirements:** Tài liệu mô tả yêu cầu chức năng, phi chức năng và user stories.
- **Architecture:** Tài liệu thiết kế kiến trúc hệ thống, luồng dữ liệu và sơ đồ thành phần.
- **Database Documentation:** Tài liệu thiết kế cơ sở dữ liệu, sơ đồ ERD và đặc tả dữ liệu.
- **API Documentation:** Tài liệu đặc tả các giao diện lập trình ứng dụng (API contracts, OpenAPI/Swagger specifications).
- **UI/UX Documentation:** Tài liệu thiết kế giao diện, luồng trải nghiệm người dùng, design system và wireframes.
